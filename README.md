# RashedTV

Android IPTV player project built with Kotlin and Jetpack Compose.

## Build

The GitHub Actions workflow builds a release APK with Java 17 and Gradle 8.7. Open **Actions** and select **Build Rashed TV APK** to inspect the build and download the `RashedTV` artifact when a run succeeds.

## Supported project direction

Android phone and Android TV. The app project is intended to support M3U/M3U8 playlists, Xtream Codes, and Stalker Portal sources, with separate Live, Movies, and Series areas.

> Build success verifies compilation only. Actual playback depends on the IPTV provider, credentials, network, and stream format.
